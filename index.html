About DQM

DQM walks direct word branches in stored knowledge trees instead of guessing tokens with heavy models.

If a path exists, you get the exact answer in microseconds. If it does not, you get a clean path notice. Simple, offline, and predictable.

clean logic • modular brains • zero bloat

What's New in v2.1.0

The latest release introduces modular architecture and standard verification:

  • External Brains: Drop any .tqm file into brains/ to load it.
  • Brain Selector: Interactive startup menu scans and lets you pick your brain.
  • Engine Compatibility: Verifies version requirements so older engines don't break.
  • Standard Metadata: Standardized fields for brain_id, author, license, and routes.
  • Normalizer Polish: Extended aliases, contraction expansion, and bug fixes.
